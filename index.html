모방할 수 없는 양대 특허 기반 원천 기술

확률적 인공지능(SLM)과 엄밀한 금융·재고 트랜잭션, 그리고 초지역 기상 방재 벡터를 결합한 로컬리의 기술적 해자입니다.

특허 제1호 (출원번호 10-2026-0182139)

비정형 자연어 주문 정형화 및 원자적 재고 제어

댓글의 일상 구어체를 언어 모델(SLM)이 1초 만에 JSON 파싱하고, 신뢰도 임계치($\tau \ge 0.75$) 검증 통과 시 PostgreSQL 배타적 행 잠금(SELECT FOR UPDATE)을 조건부 트리거하여 동시 주문 시에도 초과 판매(Overselling)를 0% 차단합니다.

// SLM 신뢰도 검증 & 원자적 행 잠금 파이프라인
IF parse_confidence >= 0.75 THEN
  SELECT stock FROM inventory WHERE item_id = :id FOR UPDATE;
  UPDATE inventory SET stock = stock - :qty;
  RETURN atomic_success(0% overselling);
특허 제2호 (출원 준비 명세서 완료)

시공간 기상 벡터 추적 및 상권 타임세일 자동 점화

S1 레이더 물리 벡터($V_{rad}$)로 1분 단위 도달 ETA를 산출하고, 252개 지자체 지형 취약 계수(불투수율·경사도)를 반영하여 과거 침수 뉴스를 매칭합니다. 보행 유동인구 감쇠율($D_{foot} \ge 0.40$) 감지 시 상점주에게 우천 세일을 자동 점화합니다.
