SECTION 03. DUAL PATENT MOAT

양대 특허(Dual Patent) 기술적 해자 인터랙티브 쇼케이스

단순 비즈니스 아이디어가 아닌, 독자적인 알고리즘과 데이터베이스 트랜잭션 수준에서 완전 구현된 2건의 정부 공인 원천 특허 기술입니다.

특허 제1호 (출원 제10-2026-0182139호)
비정형 자연어 주문 정형화 & SELECT FOR UPDATE 원자적 재고 락

소상공인 타임세일·공동구매 댓글에서 발생하는 비정형 구어체 주문을 실시간 정형화하고, 동시성 트랜잭션 충돌 시 재고 오버셀링(초과 판매)을 0.00% 완전 차단합니다.

  • 01. HybridOrderParsingEngine.ts: 형태소 정규식 룰베이스 선파싱(0ms/비용0원, 85% 처리) + 복합 발화 실패 시 LLM 구조화 Fallback 연계.
  • 02. SELECT FOR UPDATE 원자적 행 잠금: Postgres 배타적 락으로 commerce_time_sales.confirmed_stock을 격리 차감하여 동시 접속 시에도 100% 무결점 보장.
  • 03. 지역화폐 1.0% 에스크로 마진: 노쇼 방지 에스크로 결제 파이프라인과 연동하여 안전 결제 및 가맹점 정산 완결.

-- [특허 1호] SELECT FOR UPDATE 동시성 원자적 재고 차감 RPC CREATE OR REPLACE FUNCTION process_comment_order( p_deal_id UUID, p_orderer_id UUID, p_quantity INT ) RETURNS JSONB AS $$ DECLARE v_deal RECORD; BEGIN -- 1. 배타적 행 잠금 (오버셀링 0% 방어) SELECT id, confirmed_stock, total_stock INTO v_deal FROM commerce_time_sales WHERE id = p_deal_id FOR UPDATE; -- 2. 잔여 재고 검증 IF (v_deal.confirmed_stock + p_quantity) > v_deal.total_stock THEN RETURN jsonb_build_object('success', false, 'error', 'OUT_OF_STOCK'); END IF; -- 3. 원자적 재고 갱신 및 주문 원장 기록 UPDATE commerce_time_sales SET confirmed_stock = confirmed_stock + p_quantity WHERE id = p_deal_id; INSERT INTO commerce_time_orders (deal_id, orderer_id, quantity, is_confirmed) VALUES (p_deal_id, p_orderer_id, p_quantity, true); RETURN jsonb_build_object('success', true, 'remaining', v_deal.total_stock - (v_deal.confirmed_stock + p_quantity)); END; $$ LANGUAGE plpgsql SECURITY DEFINER;
